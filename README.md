
# GA Automation

Proyek pembelajaran otomatisasi General Affair menggunakan JavaScript.

## Tujuan
Membantu pekerjaan operasional kantor menjadi lebih mudah dan efisien.

## Rencana Fitur
- Daily Needs Analysis
- Monitoring stok ATK
- Monitoring maintenance
- Monitoring listrik kantor
- Laporan kebutuhan bulanan

## Teknologi
- HTML
- CSS
- JavaScript
- GitHub
